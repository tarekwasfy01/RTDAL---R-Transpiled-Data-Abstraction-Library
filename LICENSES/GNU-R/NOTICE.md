# GNU R-derived translations

`toolchain/r2go/converted/rgo` and `toolchain/r2go/converted/rprimitive`
contain translations of GNU R C entry points. Their manifests and translation
reports preserve the available mapping information. Original R code remains
copyright its upstream authors; translation does not replace its licence with
the root BSD licence or R2Go's MIT licence.

`COPYING` and `COPYRIGHTS` are preserved verbatim from the local GNU R reference
distribution. The upstream project is https://www.r-project.org/ and the source
distribution is available at https://cran.r-project.org/src/base/ . The available
translation metadata does not identify one exact upstream commit for all input
snippets; no complete provenance or licence-compliance audit is claimed.

The GoPackage adaptation on 2026-08-30 changes module import paths and Go
formatting and adds a public API; it does not claim authorship of upstream code.
